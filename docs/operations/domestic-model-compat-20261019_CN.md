## 保留与新增的通用修复

### 动态工具字段与可保真选路

- `dto.Message.Tools` 用 RawMessage 保留消息级工具定义及精确数字；真实工具加载消息不附加 `content:null`。
- 普通消息、空数组和 null 工具字段保留原 content 语义，空工具声明不会触发不必要的候选拒绝。
- 渠道系统提示不写进工具加载消息；工具估算包含动态声明。
- Chat → Messages/Responses/Gemini 等当前转换无法保留工具的历史位置时，在出站前返回有本地身份标记的 422，并排除当前候选。已配置的原生 Chat 出口可接管。
- 透传开关不允许把 Chat 请求直接发送到 Messages 端点；全局 Chat → Responses 规则使用实际生效条件判断。
- 外部同名错误码不能获得本地候选切换例外。已输出、指定渠道、亲和和预算阻断保持。
- 合成 HTTP 测试确认：不兼容候选零出站，原生备用仅调用一次，工具没有提升到顶层。

CPA 端同样保留声明位置、严格 Schema 与工具名称识别，并在候选资格和实际转换中一致排除有损转换；两边不相互依赖对方恢复已经丢失的字段。

### 搜索次数：透传、计数、结算分别保留

- Chat / Responses / Messages 普通与 SSE 统一读取 `usage.server_tool_use.web_search_requests`。
- 未报告/null、明确零、正整数分开；累计帧覆盖而不相加，后续缺失字段不擦除早期已报告值。
- 跨协议转换保留该字段，不加入 token 总数。只有上游 usage 字段有效，模型正文里的同名 JSON 不参与计数。
- 实报次数替代输出项推断及旧上下文计数，避免同一搜索重复扣费；沿用原有 preview 优先级及其模型专属价格。
- 计数与价格分开记录：日志新增 `server_tool_use` 和 `tool_usage_source=upstream_reported`；零价格仍保留实际次数。
- 不修改模型价格、分组倍率、账单表达式或工具单价。修复漏计后，原来漏掉的搜索将按既有配置进入结算；这属于行为变化，正式发布前应复核所需售价。
- 负数、小数、字符串、溢出及错误对象类型明确拒绝，包括 Chat SSE 中的 `1e999`。错误不透传为成功，不产生 DONE/completed，不触发重新生成；已输出时保留此前实报用量，不估算坏帧里的未知用量。
